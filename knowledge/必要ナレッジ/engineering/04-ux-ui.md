# 04｜UX・UI

## 目的
見た目を整えるだけでなく、顧客の目的と利用者の行動から「分かりやすい画面・導線」を設計できるようにする。

## 目標レベル
**Lv2〜3。** デザイナー級の表現力は不要だが、情報設計と基本UIの良し悪しを判断できる。

## 必要知識
- ユーザー目的・利用シーンの整理
- 情報設計、サイトマップ、画面遷移
- visual hierarchy、余白、整列、コントラスト
- typography、色、コンポーネント統一
- CTA、フォーム、navigation
- mobile first
- loading / empty / error / success state
- accessibility（文字サイズ、コントラスト、タップ領域、keyboard）
- Figmaの基本操作

## ここまでできれば十分
- ワイヤーフレームから画面構成を決められる
- 「何を一番見せるべきか」を説明できる
- CTAの位置やフォーム項目を減らす判断ができる
- スマホ画面で操作しづらい箇所を指摘できる
- 既存サイトを見て改善案を3〜5個出せる

## 習得方法
1. Material Design / Apple HIGの基本原則を読む
2. Figmaで既存サイトのワイヤーフレームを再現
3. 良い地域店舗サイトを10件観察して共通点をメモ
4. Machinologyサンプルを自分でUXレビュー

## 実践課題
既存の店舗サイト1件を選び、現状課題→改善ワイヤー→改善理由を1枚にまとめる。

## 完了判定
- [ ] ユーザー導線を図にできる
- [ ] 情報優先度を決められる
- [ ] 基本UI原則を説明できる
- [ ] スマホUXレビューができる
- [ ] Figmaで簡単なワイヤーを作れる
