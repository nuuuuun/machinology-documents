# 46｜ノーコード・ローコード

## 目的
「コードを書くこと」が目的化しないよう、既製・ノーコードで十分な案件を判断できるようにする。

## 目標レベル
**Lv2。** 全製品に詳しくなる必要はなく、カテゴリと制約を理解して比較できる。

## 必要知識
- Web builder：STUDIO / Wix等
- CMS：WordPress等
- EC：Shopify等
- app/DB：Glide / AppSheet / Bubble等
- automation：Make / Zapier / n8n等
- template、CMS、form、auth、workflowの概念
- pricing、vendor lock-in、exportability
- custom domain、SEO、権限、API連携の制約

## 選定観点
- 初期費用
- 月額
- 顧客自身で更新可能か
- 必要機能を満たすか
- 将来拡張
- データexport
- 運用難易度

## ここまでできれば十分
- Web制作でコード/ノーコードの比較提案ができる
- AppSheet等で簡単な内部業務アプリを試作できる
- lock-inや制限を顧客へ説明できる

## 習得方法
各カテゴリ1サービスだけ実際に触る。全サービスの網羅学習は不要。

## 実践課題
同一要件を「Flutterで作る場合」と「AppSheet等で作る場合」で費用・期間・制約比較する。

- [ ] build vs buyを比較できる
- [ ] 主要カテゴリを説明できる
- [ ] 1つのno-codeツールでPoCを作れる
