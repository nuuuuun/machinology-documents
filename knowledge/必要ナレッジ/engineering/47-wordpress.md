# 47｜WordPress

## 目的
既存WordPressサイトの調査・移管・軽微な保守を行えるようにする。

## 目標レベル
**Lv2。** WordPress専門制作会社レベルは不要。既存顧客サイトを壊さず扱えることが目的。

## 必要知識
- WordPress core / theme / plugin
- wp-admin
- post/page/media/menu
- theme、child theme概要
- plugin update
- PHP/MySQLが使われていること
- wp-config.php
- permalink
- backup/restore
- migration
- security update
- staging
- caching
- common trouble（plugin conflict、PHP version等）

## ここまでできれば十分
- 管理画面から構成を調査できる
- 更新前にbackupできる
- plugin/theme更新リスクを説明できる
- サーバー移管の基本手順を理解する
- 静的化・別基盤移行の可否を判断できる

## 習得方法
- WordPress Learn公式教材
- local/staging環境を1つ構築
- backup→update→restoreを実験

## 実践課題
テストWordPressを別環境へmigrationし、URL変更・SSL確認まで行う。

## 完了判定
- [ ] WordPress構成要素を説明できる
- [ ] backup/restoreできる
- [ ] update前後の確認ができる
- [ ] 移管案件のリスクを列挙できる
