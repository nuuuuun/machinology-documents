# 25｜Excel・Google Sheets

## 目的
小規模事業者の既存業務を理解し、「新規システムを作らず表計算で改善できる」判断と実装をできるようにする。

## 目標レベル
**Lv2〜3。** 日常業務の集計・整形・簡易管理を作れる。

## 必要知識
- table/range、filter、sort
- absolute/relative reference
- IF / SUMIFS / COUNTIFS
- XLOOKUPまたはINDEX/MATCH
- FILTER / UNIQUE等の動的配列
- text/date functions
- data validation
- conditional formatting
- pivot table
- chart基本
- CSV import/export、文字コード
- Google Sheets共有・権限
- Apps Scriptの存在と基本用途

## ここまでできれば十分
- 売上・顧客・在庫の簡単な管理表を作れる
- 複数表をlookupで関連付けられる
- pivotで月次集計できる
- CSVをシステム入出力用に整形できる

## 習得方法
- Microsoft Learn / Google Sheets Training
- 実際の業務を想定した表を3種類作る
- 必要になった関数を都度公式ヘルプで調べる

## 実践課題
店舗の売上明細CSVから、月別・カテゴリ別売上を集計するダッシュボードを作る。

## 完了判定
- [ ] lookup/条件集計を使える
- [ ] pivotを作れる
- [ ] CSVトラブルを基本切り分けできる
- [ ] 「アプリ不要、Sheetsで十分」と判断できるケースが分かる
