# 03｜Web制作

## 目的
Machinologyの標準的な小規模Webサイトを、要件整理から実装・公開まで自力で完結できる状態を目指す。

## 目標レベル
**Lv3：提案・設計までできる。** 単にHTML/CSSを書けるだけでなく、構成・レスポンシブ・フォーム・基本SEO・公開まで判断できる。

## 必要知識
### HTML
- semantic HTML（header/nav/main/section/article/footer）
- 見出し構造、リンク、画像、フォーム、table
- accessibilityを意識したlabel・alt・button

### CSS
- box model、display、position
- Flexbox / Grid
- responsive design、media query
- CSS変数、擬似クラス、基本的な設計整理
- 余白・文字サイズ・画像比率の調整

### JavaScript
- 変数、関数、配列・オブジェクト
- DOM取得・変更、event
- form validation
- async/await、fetch、JSON
- 外部APIを1つ呼び出せる

### Web基礎
- HTTP/HTTPS、URL、request/responseの概要
- browser devtools
- favicon、OGP、meta、title/description
- sitemap / robots.txt の役割
- Lighthouseの基本項目

## ここまでできれば十分
- 5〜10ページ程度の店舗サイトを作れる
- PC/スマホで崩れない
- 問い合わせフォームを実装・接続できる
- title/description/heading/altを適切に設定できる
- Chrome DevToolsで表示崩れや通信エラーを切り分けられる
- Lighthouseで重大な問題を説明・改善できる

## 習得方法
1. MDNでHTML/CSS/JavaScriptの該当項目を確認
2. 小さな模写サイトを1つ制作
3. Machinologyのサンプルサイトをゼロから1つ再構築
4. 実際にホスティングしてスマホ実機確認

## 実践課題
架空の飲食店サイトを、トップ・店舗情報・メニュー・アクセス・問い合わせの5ページで制作する。

## 完了判定
- [ ] HTML構造を理由付きで説明できる
- [ ] Flex/Gridを使い分けられる
- [ ] レスポンシブを自力調整できる
- [ ] JSでフォームや簡単なUIを実装できる
- [ ] 公開前チェックを一人で実施できる
