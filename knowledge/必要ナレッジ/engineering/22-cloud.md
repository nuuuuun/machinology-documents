# 22｜クラウド

## 目的
Firebase等で不足する案件に対し、クラウド構成の選択肢とコスト・運用負荷を判断できるようにする。

## 目標レベル
**Lv2。** AWS専門家になる必要はなく、主要サービスカテゴリと使い分けが分かればよい。

## 必要知識
- IaaS/PaaS/SaaS/serverless
- region / availability zone概要
- compute / storage / database / CDN / DNS
- object storage
- managed DB
- serverless functions
- IAMの基本
- network/VPCの概念
- monitoring/logging
- usage based pricing
- backup/availability

## ここまでできれば十分
- Firebase、Vercel、Cloudflare、AWS等の違いを大枠で説明できる
- static site、API、file storage、DBの配置先候補を出せる
- コストと保守負担で選定できる

## 習得方法
- AWS Cloud Practitioner相当の無料教材を「資格取得目的ではなく全体像把握」で学ぶ
- Cloudflare/Firebaseのarchitecture docsを読む
- 小さなserverless APIを1つdeploy

## 完了判定
- [ ] cloud主要カテゴリを説明できる
- [ ] managed/serverlessを優先する理由が分かる
- [ ] IAM最小権限の概念が分かる
- [ ] 月額コストの大まかな見積要素を挙げられる
